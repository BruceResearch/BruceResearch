#### Featured projects
- [**LUCIDus3**](https://github.com/BruceResearch/LUCIDus3) — R package for latent unknown clustering that integrates multi-omics data (early / parallel / serial integration), continuously enhanced from the CRAN release.
- [**Praxis-BGM**](https://github.com/BruceResearch/Praxis-BGM) — Prior-Augmented Bayesian Gaussian Mixture model via natural-gradient variational inference; a semi-supervised transfer-learning framework for clustering omics, multi-omics, and single-cell data.
- [**Praxis-BGM R interface**](https://github.com/BruceResearch/Praxis_BGM_R_interface) — R wrapper around the Python Praxis-BGM package via `reticulate`.
